Lámina conceptual con contenido ficticio. Las piezas de esta página describen la experiencia y sus responsabilidades visibles.

## 01 / Terminal

Entrada de importes y registro de operaciones con controles grandes.

**En el recorrido:** Preparar inventario.

**Responsabilidad relacionada:** Interacción de jornada.

## 02 / Inventario

Recepciones, libros, búsqueda y seguimiento de existencias.

**En el recorrido:** Registrar una operación.

**Responsabilidad relacionada:** Ventas e inventario.

## 03 / Calendario

Consulta diaria y mensual de ventas, liquidaciones y planificación.

**En el recorrido:** Revisar el día.

**Responsabilidad relacionada:** Calendario e informes.

## 04 / Informes

Desgloses y documentos para revisar la actividad guardada.

**En el recorrido:** Consultar el informe.

**Responsabilidad relacionada:** Datos locales.

## Relación entre las piezas

Preparar inventario → Registrar una operación → Revisar el día → Consultar el informe.

El recorrido permite discutir jerarquía, navegación y continuidad. La representación se simplifica a propósito y no publica los contratos internos de implementación.
